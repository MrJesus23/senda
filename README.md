# SENDA

Sistema de Evaluación Natural y Dinámica de la Atmósfera.
App móvil que traduce datos meteorológicos en alertas de impacto físico
(confort térmico, calidad del aire y escorrentía) para el Valle de Aburrá.

## Estructura
- `backend/` API en Python (FastAPI)
- `app/` App móvil (React Native + Expo + TypeScript)
- `docs/` Documentación, contrato de la API y fórmulas físicas
